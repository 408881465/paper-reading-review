# 值得关注的两类引用文献

生成 review 的**最后一节**，置于参考文献表**之前**（它是导读的产出，
不属于原文的引用信息）。

## 0. 为什么要做这一节

原文的参考文献表只是**书目**，不回答读者真正关心的问题：
- 哪些文献是**这个领域的支柱**（不读会漏掉根本立场）？
- 哪些文献是**我该去反驳的对象**（与本文/我的判断对立）？

原文作者的引用行为本身就是一种**元数据**——它透露了作者站在什么立场、
依托什么传统、回避了什么。**把引用行为读出来，比读参考文献表本身更有价值。**

本节输出**两组**文献，每组 3–5 条，按重要性排序，并说明**为什么值得关注**。

---

## 1. 第一组：高引用量 / 支柱性文献

### 怎么判断「引用量大」

**没有联网时，按以下信号排序**（可靠性由高到低）：

| 判据 | 说明 | 可靠性 |
|---|---|---|
| **正文提及次数** | 该文献在正文被反复提及（不只出现在文献表） | 高 |
| **被用作框架依据** | 作者说「××指出……」「按照××的模型……」并据此展开论证 | 高 |
| **成组引用** | 多条同主题文献被并列引用（如「国内外研究均认为……」） | 中 |
| **推测性判断** | 引文处无具体年份、或未直接引用而是以「有学者指出」带过 | 低 |

**关键**：注明判断依据。**不要只写「引用较多」，要写「正文提及 4 次，
且为第二节论证的框架依据」**。

### 常见陷阱

- **政策文件不等于高引用**。政策被引是「制度性引用」，反映的是合规要求，
  不是学术影响力。应单列，或在说明中标注「政策性引用」。
- **经典文献不等于有用**。可能与本文主题无关。此处只列**与本文议题相关**的。

### 输出格式

```markdown
### 支柱性文献（引用量大 / 论证所依托）

1. **[7] 丁世强，马潇，魏拥军. 中小学人工智能教师专业素养框架研究[J].
   电化教育研究，2023，44(6)：120-128.**
   - **关注理由**：本文「教师须系统性重构素养」的直接来源（同刊同期，作者
     自陈的空白即由此而来）；本文的教师角色转型判断与其一致。
   - **怎么用**：读它可判断本文的框架是否只是该文的**复述**——若六项能力与
     其高度重合而本文未说明，则「解构」一说存疑。
   - **立场**：**支持**本文（但概念命名与本文不同，见下节）
```

## 2. 第二组：观点相反 / 需要对话的文献

这是本节**最有价值**的一半。原文回避了什么，往往比它支持什么更能说明问题。

### 四种「相反」的来源

| 类型 | 怎么发现 | 说明 |
|---|---|---|
| **结论相反** | 同一问题，本文与某文献结论对立 | 最显性，须解释分歧来源（方法差异？情境差异？） |
| **概念/术语冲突** | 两文用同一个词指不同的事 | 最隐蔽，**危害最大**——会妨碍文献积累 |
| **框架冲突** | 两套框架对同一维度做了不相容的划分 | 影响综述的组织方式 |
| **被回避的文献** | 文献表里有，但正文从未实质使用 | ⚠️ **最需警惕**：作者可能知情但回避了反驳它 |

**「被回避的文献」尤其要查**：凡是列入参考文献表、正文却只有引号而无实质
论述的，或仅在「某某等人指出…」中一笔带过的，都要看它是否与本文立场相左。

### 三种情况要写清

1. **真冲突**：明确指出「本文与之结论相反」+ 分歧可能的原因。
2. **概念冲突**：**同名不同义**要逐字标出（本文「教学素养」vs 他文「专业素养」
   的三维度符号相近而内涵不同）。这类冲突**不解决就无法做综述**。
3. **本文回避**：明确写「本文列入文献表但未实质回应」，这是本文的批评点。

### 输出格式

```markdown
### 需要对话的文献（观点相反 / 概念冲突 / 被回避）

1. **[7] 丁世强等《中小学人工智能教师专业素养框架研究》**
   - **冲突类型**：**概念命名冲突 + 覆盖范围重叠**
   - **具体分歧**：本文界定「教学素养」为教师素养的「核心子系统」；
     该文直接以「中小学人工智能**教师**专业素养框架」为题。本文未说明二者边界。
   - **为什么会出问题**：本文的三维度（信念／知识／能力）与其三维度
     （专业知识／专业能力／专业情感）**符号相近而内涵不同**——「教学信念」
     不等于「专业情感」。若综述同时引用两套框架，读者会误以为它们同义。
   - **建议动作**：引用本文框架时**必须同时标注该文并说明关系**，
     否则会把两套不同框架误当作同一套的细分。

2. **[××] ×××（观点相反）**
   - **冲突类型**：结论相反
   - **分歧**：本文认为 A；该文认为 B
   - **可能原因**：方法差异 / 样本差异 / 时期差异 / 情境差异（须写明是哪一种）
   - **建议动作**：列为后续研究的关键裁决点
```

## 3. 纪律

1. **不编造**。只能依据原文**实际引用的**文献。若原文某观点对立但未引用，
   **不得凭记忆补充**——须写「原文未引用相关研究，无法核对」。
2. **注明判断依据**。每条都要写清「为何值得关注」，不能只列书名。
3. **不给检索建议**。本节只处理**已引用的**文献；若读者需要更多，
   应转向 `cnki-skills` / `global-biblio-base`。**不写「建议进一步查阅 XX」**
   ——那是检索建议，超出本技能边界。
4. **两组可重叠但须分别标注**：同一篇文献既被高频引用又与本文冲突时，
   在两组都列，但说明的角度不同（第一组说「它的影响力」，第二组说「它的风险」）。
5. **本节是导读的产出**，须与「客观转述／本文评述」的标记规则一致：
   「为什么值得关注」是本文评述，须标明。

## 4. 放在哪里

```
……
## 六、读后总评
## 七、值得关注的引用文献      ← 本节，新
   7.1 支柱性文献（引用量大 / 论证所依托）
   7.2 需要对话的文献（观点相反 / 概念冲突 / 被回避）
## 八、引用信息（GB/T 7714-2015）  ← 原文的参考文献表
```

**为何置于原文参考文献表之前**：本节是**导读的产出**（读者据此行动），
原文文献表是**原文的组成**（读者据此回查）。产出在前、原料在后，
读起来才顺。形态 B / C 同理，把本节放在完整文献表之前。
