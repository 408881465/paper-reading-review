# 从阅读密码到 Review 文档：三种产出形态

本文件规定 review 文档**怎么写**。阅读密码的定义见 `reading-codes.md`。

## 0. 三种产出形态与路由

| 形态 | 输入 | 产出 | 适用场景 |
|---|---|---|---|
| **A. 单篇深度导读** | 1 篇论文 | 结构化解码 + 评述 | 精读一篇、备课讲解、研究生入门训练、判断一篇文献是否值得纳入自己的综述 |
| **B. 多篇主题综述** | 3+ 篇同主题论文 | 主题聚类 + 空白论证 + 提纲 | 写文献综述章节、开题、课题申报书的研究现状 |
| **C. 多篇对比评述** | 2+ 篇可比论文 | 对比矩阵 + 共识/分歧 | 综述答辩、评估一个研究领域的方法演进、期刊组稿 |

**默认判断**：输入 1 篇 → A；输入多篇且**主题相近**（可归为同一组「现有文献综述」）→ B；
输入多篇但**可逐维度对比**（同问题不同方法/不同结论）→ C。

用户未指明时，若多篇文献同主题，优先 B；若多篇文献方法/结论差异大且用户
关心「谁对谁错」，优先 C。拿不准时，问一句，不要默认。

## 1. 通用铁律（三形态共享）

### 1.1 摘要优先原则

**读摘要 → 判断价值 → 再决定是否读全文。** 摘要 150–200 字已含
现有文献批评 / 空白 / 作者提出的主要问题 / 研究结果，足以判定该文与你的主题的相关性。
读完摘要若发现研究结果与你的主题不相干，**立即停止，不必读完全文**。

**但摘要阶段「答案」（WTDD）是缺位的**——主要观点要到结论才完整交付。
因此摘要只能支撑「该文是否相关」的判断，**不能支撑「作者的主张是否站得住」
的判断**。后者必须读到结论。这也是形态 A 不能只读摘要就动笔的原因。

单篇导读中，若摘要缺失或用户只给了正文，直接从前言读起，并说明该缺失。

### 1.1b 一问一答必须分开

**WTD 是作者提出的主要问题（问句），WTDD 是作者给出的答案/主要观点（答句）**。写 review 时：

- 两者**分栏填写**，不合并成一句「作者研究了 X 并发现 Y」。
- 核对**问答对齐度**：完全对齐 / 承诺大于交付 / 交付超出承诺（详见
  `reading-codes.md` 第 1 节）。
- **最常见的错误**是把作者的**主张**当成作者的**问题**来复述——等于把结论
  伪装成前提，读者会误判该研究要解决什么。凡核对问答不对齐处，即为评述抓手。

### 1.2 证据必须可回指

每一条评述都要能回答：**这句话对应原文的哪一句/哪一段？**
- 引用原句时用引号标出，并注明位置（章节名 + 页码或段落序号）。
- 禁止把作者未说过的话归给作者。宁可写「原文未明确说明……」。
- 分不清是作者观点还是自己判断时，**显式分开**（「作者主张……」vs「本文评述认为……」）。

### 1.3 区分「文献说什么」与「你怎么评」

Review 最容易失手的地方：把读者的推断写成作者的结论。全文用一致的
标记区分，例如：

- 客观转述：`作者指出（p.xx）：……`
- 本文评述：`本文认为该处存在一个问题：……`
- 存疑待查：`原文此处表述含混，未见明确说明，需回查全文。`

### 1.4 覆盖完整度要求

**书写规范**：review 文档中**一律使用中文密码名**，缩写在首次出现处加括注
（如「研究结果（ROF）」），此后可直接用中文名。不使用纯缩写行文。

一篇合格的导读**必须**覆盖：作者提出的主要问题、作者给出的答案、研究结果、理论依据、
空白、现有文献批评、一致的研究发现、相反的研究发现、未来研究建议，
加上你挖出的批评点、明显的遗漏点、待探讨的相关问题、能否理顺。
缺失项若原文确实没有，**写「原文未见」并说明其含义**（往往是重要的评述点）。
第七节「值得关注的引用文献」同样必填——见2.4。

## 2. 形态 A：单篇深度导读

### 2.0 详版 + 速览双输出（默认行为）

形态 A **默认产出两份**：

| 文件 | 内容 | 用途 |
|---|---|---|
| `<论文简称>-导读.md` | 完整解码（1500–10000 字） | 判断能否引用、怎么引用 |
| `<论文简称>-速览.md` | 一页纸（`assets/quick-review-template.md`） | **决定要不要读全文** |

**为什么速览不是「详版的缩写」**：两者的**读者与问题不同**。
详版回答「这篇文献讲了什么、可靠吗、该怎么引」；速览回答
「值不值得我现在花一小时读原文」。速览的落点是**判定与取舍**，
不是内容复述——所以它只留「一句话结论 + 三条要点 + 一个批评点 + 判定 +
两条「值得关注的引用文献」，不铺陈解码过程。

**速览须能独立成立**：读者没看详版也能据此决定读不读原文。
**速览只做减法，不做另一次解码**——不得出现详版里没有的新判断。

### 2.1 文档骨架

```markdown
# 《论文标题》导读

> 作者 · 期刊 · 年份 · DOI
> 解码依据：阅读密码表（会读才会写）

## 一、导读摘要      ← 150–200 字，五句骨架：现有文献综述 / 现有文献批评-空白 /
                            作者提出的主要问题 / 研究结果 / 启示
## 二、研究定位
   2.1 作者提出的主要问题及主要观点（WTD / WTDD）——一问一答，分栏填 + 对齐度核对
   2.2 理论依据（RAT）—— 为什么这个问题值得做
   2.3 承前：作者的现有文献综述与现有文献批评（SPL / CPL）
## 三、研究实施
   3.1 数据与材料
   3.2 方法与分析策略
   3.3 方法上的批评点（POC）  ← 重点，必须具体到变量/测度/样本
## 四、研究结果与学术定位
   4.1 核心发现（ROF）
   4.2 与既有文献的一致（RCL）
   4.3 与既有文献的冲突（RTC）
## 五、本文贡献与局限
   5.1 贡献（空白 → 理论依据 → 作者提出的主要问题 的闭合程度）
   5.2 遗漏点与待探讨问题（MOP / RPP）
   5.3 作者自陈的局限与未来研究建议（RFW）
   5.4 逻辑上能否理顺（WIL）—— 文中矛盾是否可解
## 六、读后总评
   - 这篇论文是否值得纳入我的文献综述？一句话判定 + 理由
   - 可直接借用的批评点（供自己写作使用）
## 七、值得关注的引用文献
   7.1 支柱性文献（引用量大 / 论证所依托）
   7.2 需要对话的文献（观点相反 / 概念冲突 / 被回避）
## 八、引用信息（GB/T 7714-2015）〔**原文的**文献表，非本导读产出〕
```

### 2.2 各节的写法要点

**第二节 研究定位**——回答「意义何在」。
若提不出**主要问题**，说明文章定位模糊。
这一节还要核对**问答对齐度**：提出的问题，是否在答案里都给了交代。承诺大于交付者，可作遗漏点的来源；
交付超出承诺者，须辨明是真贡献还是 Discussion 里的即兴发挥。
「理论依据」缺失是重灾区：多数论文的「空白」之后没有「那又怎么样」的正式回答，
review 中要**明确指出**这一点及其后果（研究必要性悬空）。

**第三节 方法与批评点**——全篇最有价值的一节。
批评点必须落在**可操作的具体处**（测度效度、样本代表性、缺失数据处理、
因果推断越界、效度威胁），不要写「方法有待加强」这类无抓手的空话。
定性研究转而追问资料生成过程（见 `reading-codes.md` 第 2 节路径二）。

**第四、五节 贡献与局限**——是全篇**评述的重心**，不是摘要的复述。
- 贡献：看「现有文献综述 → 现有文献批评 → 空白 → 理论依据 → 作者提出的主要问题」
  这条链**是否闭合**。链条完整 → 贡献清楚。
- 局限：区分「作者自陈的局限」（对应「未来研究建议」）与「本文发现的局限」（对应「批评点 / 明显的遗漏点」）。
  两者分开写，不混为一谈——作者没看见的局限往往比自陈的更有价值。

**第六节 读后总评**——必须给出一句**可执行的判定**，
不能写「有一定参考价值」这种和稀泥的话。判定口径见**第 5 节**。

### 2.3 长度参考

**1500–10000 字**（2026-10-07 上调；原上限 3000 字已废止）。

放宽上限是因为实践中发现**理论建构型、政策类、评述类文献**
（本项目 2026-10-06 读夏志华《教师教学素养》一篇即 3560 字）的评述对象是
框架本身，而非方法可靠性——需要承载的概念辨析、分层判准分析、引文核查
远超实证研究一篇的常规分量。原 3000 字上限会逼着评述退化为摘要。

**下限 1500 字仍然有效**：低于此通常意味着批评点、明显的遗漏点挖得不够深。

**超上限时的处理**：不要闷头逐句微调（实测单轮仅压 50–150 字，收益极低）。
先确认是否可整体重写某节（单节可压 300–500 字）；确实压不动就**在文末
标注字数并说明理由**，同时给出**压缩取舍顺序**（保留价值从高到低）。

### 2.4 第七节怎么写（不可跳过）

**这是导读的产出，不是原文的引用信息**——放在原文参考文献表**之前**。
方法详见 `cited-literature.md`。两条纪律：

- **不编造**：只处理原文**已引用**的文献。原文未引用而观点对立的，
  须写「原文未引用相关研究，无法核对」。
- **不给检索建议**：不写「建议进一步查阅 XX」——那是检索的事，
  属 `cnki-skills` / `global-biblio-base`。

**「被回避的文献」最需警惕**：列入文献表、正文却只有引号而无实质论述的，
或仅在「某某等人指出……」中一笔带过的——要去查它是否与本文立场相左。

### 2.5 理论建构型文献（无数据）的四条替代路径

`reading-codes.md` 第 2 节的批评点路径（测度效度、资料生成过程）是为**有数据**
的实证研究写的。理论建构型、政策类、评述类文献没有数据与方法部分，
不能硬套，改查下列四条：

1. **框架来源是否交代**——概念的出处与选取理由有没有说明，还是直接拿来用？
2. **分层判准是否声明**——各层级／各类别按什么标准划分，边界是否互斥穷尽？
3. **概念是否同名不同义**——与既有文献共用术语时，内涵是否已被悄悄替换？
4. **策略与框架的映射是否建立**——提出的框架与实际主张之间，是否有可检验的对应关系？

这四条的产出同样记入「批评点」，不能因为「没有数据」就放弃第三节的评述深度。

## 3. 形态 B：多篇主题综述

### 3.1 RCOS 整合表先行（不可跳过）

**阅读密码整合表（Reading Code Organization Sheet, RCOS）** 是形态 B 的
必备中间工件。步骤：

1. 逐篇填写 RCOS（模板见 `assets/rcos-template.csv`），
   字段：**序号 / 作者 / 年份 / 标题 / 来源 / 现有文献综述 / 现有文献批评 / 空白 / 研究结果 / 未来研究建议 / 批评点·待探讨的相关问题**
2. 录入时机：**读完当天**。隔天补录时不要再逐页重读原文，只做机械誊抄
   （要点已在留白与荧光笔中）。
3. 多篇文献时用 `scripts/build_review.py` 的 `rcos` 子命令做校验与聚类提示。

### 3.2 从 RCOS 到提纲

这是形态 B 的核心转换。**不要按作者和年份罗列**（那是洗衣店接衣单），
必须**按主题聚类**：

1. **合并「研究结果」与「现有文献综述」两栏** → 找出反复出现的模式 → 压缩成 **8–10 个主题**。
   同一主题下的多篇文献，只在该主题段落里被提及，而非各自开段。
2. **考察「现有文献综述 → 现有文献批评」的共有模式** → 把反复出现的空白归类 → 组织成 **3–5 组主题**。
3. **写理论依据** → 展示你将如何弥补这些缺陷，理由同样按 3–5 个主题组织。

**提纲模板**：

```markdown
# 综述提纲
1. 现有文献综述（现有文献说了什么）
   A–H. 主题 1–8
2. 现有文献批评 / 空白（文献哪里不足、缺什么）
   A–C. 主题 1–3
3. 理论依据（我的研究为何必要）
   A–C. 主题 1–3
```

### 3.3 文档骨架

```markdown
# 主题综述：<主题名>

> 文献范围：N 篇（<起止年份>）· 检索/来源说明 · 解码依据：阅读密码表

## 一、综述摘要
## 二、文献范围与筛选说明
   （检索式/来源、纳入排除标准、文献数量）
## 三、现有文献的主题格局（现有文献综述）
   3.1 主题一（…）
   …按 8–10 个主题展开
## 四、文献的批评与空白（现有文献批评 / 空白）
   4.1 反复出现的批评点
   4.2 系统性研究空白（3–5 组主题）
   4.3 作者们共同指向的未来研究（未来研究建议 的汇聚）
## 五、理论依据与研究必要性（理论依据）
## 六、方法论观察
   （批评点 汇总：这些研究共同的方法短板——这一节往往是综述最有分量的部分）
## 七、结论与研究机会
## 八、值得关注的引用文献
   8.1 支柱性文献（本综述中被反复依托的 3–5 篇）
   8.2 需要对话的文献（观点相反 / 概念冲突 / 被回避）
## 九、参考文献（GB/T 7714-2015）〔本综述自己的文献表〕
```

### 3.4 关键纪律

- **「现有文献综述」段落内不得「一树吊死」**：同一作者不得在相邻段落反复独占篇幅。
  出现即说明主题聚类失败，需回到 RCOS 重新聚类。
- **主题是聚类结果，不是作者顺序**：写完检查每个主题下的文献数，
  若某主题只挂 1 篇而另一主题挂了 8 篇，说明聚类不均，需重新划分。
- **空白必须可弥合**：每个空白后都要跟一句「因此可以开展的研究是……」
  （即理论依据），否则空白沦为空谈。
- **批评点汇总节是差异化重点**：多数综述止步于「总结别人做了什么」，
  很少系统汇总「这些研究共同的方法论短板」——后者才是读者最需要的。

## 4. 形态 C：多篇对比评述

### 4.1 文档骨架

```markdown
# 对比评述：<议题>

> 涉及文献：N 篇 · 解码依据：阅读密码表

## 一、对比综述（150 字）
## 二、对比矩阵（全文骨架，见 4.2）
## 三、研究问题与理论依据对比（WTD / RAT）
## 四、研究设计对比（材料 / 方法 / 样本）
## 五、主要发现对比（研究结果）
## 六、共识与分歧
   6.1 跨文献一致处（对应「一致的研究发现」的横向汇总）
   6.2 冲突之处（对应「相反的研究发现」的横向汇总）
   6.3 冲突的可能解释
## 七、方法论评价
   7.1 各自的方法优势
   7.2 各自的方法局限（批评点）
   7.3 冲突可能源自的方法差异
## 八、综合判断与研究机会
## 九、值得关注的引用文献
   9.1 支柱性文献（各篇论证所依托的 3–5 篇）
   9.2 需要对话的文献（观点相反 / 概念冲突 / 被回避）
## 十、参考文献（GB/T 7714-2015）〔本评述自己的文献表〕
```

> **本节骨架与 `assets/comparative-review-template.md` 逐节一致**（含节号）。
> 两者若不一致，**以模板为准**并在本处修正——模板是实际要填的东西，骨架只是说明。
> 历史上这两处曾错位一节（对比矩阵是否占节号），导致按骨架写作的人与按模板检查的人对不上。

### 4.2 对比矩阵（即第二节，作为全文骨架）

| 维度 | 作者A(年) | 作者B(年) | 作者C(年) |
|---|---|---|---|
| 研究问题（作者提出的主要问题） | | | |
| 理论依据 | | | |
| 材料与样本 | | | |
| 方法与测度 | | | |
| 核心发现（研究结果） | | | |
| 与前人关系（一致 / 相反） | | | |
| 自陈局限 / 未来研究建议 | | | |

### 4.3 关键纪律

- **分歧不等于错误**。发现冲突时，**先查方法差异**（样本、测度、时期、
  情境），再谈结论对立。多数「矛盾」是情境差异而非论断矛盾。
- **共识也需要审视**。若多篇结论高度一致，须检查是否共享同一数据源、
  同一方法传统，否则「共识」可能是方法单一造成的假象。
- 对比维度须**统一可比**：每篇都按同一组维度填表，不可因某篇缺项而改维度。

## 5. 判定口径：是否值得纳入我的文献综述

形态 A 的第六节、形态 B 的筛选环节都需要一个**明确判定**。
使用以下口径，不要打太极：

| 判定 | 条件 |
|---|---|
| **纳入（核心）** | 研究结果直接支撑本文研究问题；且理论依据清楚、链条闭合 |
| **纳入（背景）** | 现有文献综述有价值但研究结果与本文问题无直接关系；可支撑研究背景 |
| **暂不纳入** | 研究结果与本文主题相干度过低；或该文研究问题已被更新研究覆盖 |
| **待核查** | PDF 缺失/内容不完整/表述含混无法判定——**写明待核查的具体原因** |

「待核查」是合法结论，优于含糊其辞。

## 6. Review 成稿自检清单

成稿后逐条检查，任何一条不通过就返工：

- [ ] 十个结构性密码与四个策略性密码**已逐项覆盖**；
      原文确实缺失该内容的，写明「原文未见」并说明其含义
      （⚠️ **实证研究各项通常都有内容，不应出现「原文未见」**——
      若内容齐备却硬写「原文未见」，即为不实标注）
- [ ] **问题与答案分栏填写（WTD / WTDD），未合并成一句**
- [ ] **已核对问答对齐度**（完全对齐 / 承诺大于交付 / 交付超出承诺）
- [ ] 每个空白后都跟了理论依据（研究机会）
- [ ] 现有文献批评与批评点已区分：前者是作者对文献的批评，后者是本文对文献的批评
- [ ] 所有原句引用标了位置；无「作者未说过」的错误归属
- [ ] 客观转述与本文评述已标记区分
- [ ] **「值得关注的引用文献」两栏均已填写**（支柱性 + 需要对话的）
- [ ] **被回避的文献已核查**（列入文献表但正文无实质论述的，是否立场相左）
- [ ] 未出现「一树吊死」（同一作者在相邻段落反复独占）
- [ ] 主题是聚类结果而非作者顺序（检查各主题文献数是否失衡）
- [ ] 「意义何在」已回答（理论依据不悬空）
- [ ] 判定了「是否值得纳入」，且不是和稀泥
- [ ] 参考文献格式符合 GB/T 7714-2015
- [ ] 篇幅落在 1500–10000 字（形态 A）；超限时已标注理由并给出取舍顺序

## 7. 常见失败模式

| 失败模式 | 表现 | 纠正 |
|---|---|---|
| **洗衣店接衣单** | 「Smith 发现…Jones 认定…Anderson 指出…」按作者年份罗列 | 按主题重组：同一主题的文献写进同一段落 |
| **一树吊死** | 综述中反复独占篇幅讨论某一位作者 | 回到 RCOS 重新聚类，把该作者打散进各主题 |
| **只总结不批评** | 通篇复述研究结论，无现有文献批评、无批评点 | 强制补第五节（贡献与局限）；批评点要具体到测度/样本 |
| **空白空转** | 罗列了空白，但没说怎么补 | 每个空白后必须跟理论依据 |
| **译者/读者混淆** | 把自己的推断写成作者的观点 | 用显式标记区分（见 1.3） |
| **长度虚胖** | 摘要是正文的压缩复述 | 导读正文应在 1500–10000 字内完成完整解码 |
| **荧光笔式阅读** | 摘要/引言就下判断，未读到结果部分 | 强制按章节走完密码链再动笔 |
